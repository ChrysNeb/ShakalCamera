# Установка на Android

1. Откройте [последний релиз](https://github.com/ChrysNeb/ShakalCamera/releases/latest). Если предварительный релиз не показывается как latest — используйте [все релизы](https://github.com/ChrysNeb/ShakalCamera/releases).
2. Скачайте **ShakalCamera-1.0.2.apk** из раздела Assets прямо на телефон.
3. Откройте файл. Если Android попросит, разрешите установку из браузера / файлового менеджера, которым открыли APK.
4. Установите «Шакал Камеру» и разрешите доступ к камере.
5. Выберите уровень и нажмите **Снять фото**. После обработки — **Сохранить** или **Поделиться**.

Для видео переключитесь на **ВИДЕО**. Для записи звука отдельно разрешите микрофон; после выдачи разрешения нажмите запись ещё раз. Без микрофона видео записывается без звука. Повторное нажатие на кнопку останавливает запись; предел — 60 секунд.

## Быстрый гид

| Кнопка | Что делает |
| --- | --- |
| Фильтр в кадре | Включает / выключает GPU-превью: цель до 30 кадров/с, адаптивно 20/15 |
| Камера | Переключает заднюю / фронтальную камеру |
| Свет | Включает фонарик, если камера его поддерживает |
| 1× / 2× | Меняет зум в доступных пределах |
| Касание видоискателя | Фокусируется на выбранной точке |
| Из галереи | Открывает системный выбор фото / видео |
| 12/10 | Отдельный режим пиксельного искусства |
| Оригинал / Результат | Сравнивает обработку с исходником |
| Ещё шакальнее | Повторно пропускает результат через выбранный уровень |

## Где лежат файлы

После **Сохранить**: альбом `ShakalCamera` в системной галерее. На Android 10+ это `Pictures/ShakalCamera` для фото и `Movies/ShakalCamera` для видео. До нажатия «Сохранить» результат находится только в кэше приложения. Системная очистка кэша может его удалить.

Импортированные оригиналы не изменяются. Для отправки выберите **Поделиться**, затем нужный мессенджер или приложение.

## Требования и ограничения

- Android 8.0+, включая обычные ARM64-телефоны. APK универсальный, отдельную архитектуру выбирать не нужно.
- Фото сохраняются с длинной стороной до 2048 px, результат видео — 480 px.
- Видео до 60 секунд; более длинный импорт берёт первую минуту. Импорт до 200 МБ.
- Держите приложение открытым во время обработки.
- Сборка **Preview**, подписана debug-ключом. Проверки реальной камеры и аппаратного кодека на телефонах пока не выполнены.
- Видоискатель использует облегчённый фото-фильтр. Итоговое видео обрабатывается после остановки и отличается от превью.

На Android 8–9 для сохранения в галерею нужен доступ к памяти. На новых версиях разрешение на всю медиатеку не требуется.

## Если что-то пошло не так

- **Камера не открылась:** проверьте разрешение в настройках Android, закройте другое приложение камеры; можно воспользоваться импортом.
- **Нет звука:** включите звук и выдайте разрешение на микрофон.
- **Не обрабатывается ролик:** попробуйте короткий MP4 H.264; доступные кодеки зависят от устройства.
- **Не сохраняет:** проверьте свободное место и разрешение памяти на старом Android.
- **APK не обновляет установленную версию:** разные подписи сборок несовместимы. Сохраните нужные результаты в галерею перед удалением старой версии.

Для ошибки приложите модель телефона, Android, выбранный уровень и шаги — без личных фото и видео. [Создать issue](https://github.com/ChrysNeb/ShakalCamera/issues/new/choose).
